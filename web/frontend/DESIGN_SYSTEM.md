# 会社図鑑への当てはめ

見た目の正本は [DESIGN.md](DESIGN.md)（Nintendo.com 2001 の分析）。トークンの実装は `src/index.css`。部品は `src/components/`。

任天堂のワードマーク、ロゴ、マリオは使わない。ロゴピルは赤文字の「会社図鑑」、吹き出しの相手は既存の卵と業種キャラ。

## 色

地はペリウィンクルの金属板。温かい色は、進む場所と道具だけ。

| トークン | 値 | 使う所 |
| --- | --- | --- |
| `canvas` | `#7A8ABA` | 地 |
| `periwinkle` | `#8BA1D4` | 一段明るい板（業種タイル） |
| `canvas-soft` | `#9FBEE7` | ナビの下の帯 |
| `lavender` | `#ACACE7` | 表紙のヒーロー |
| `chrome` | `#3D4F97` | 面取りの下辺、補足の文字 |
| `platinum` | `#DEDEDE` | 一覧の行、開いた中身 |
| `surface` | `#FFFFFF` | カード、入力欄 |
| `carbon` | `#21242E` | ナビ、フッター、本文 |
| `signal` | `#F68D1F` | 進む矢印と確定 |
| `amber` | `#ECAB37` | 道具のボタンと印 |
| `nav-gold` | `#E48600` | ナビの文字 |
| `brand` | `#E60012` | ロゴとエラー |
| `systems-teal` | `#206479` | 比較の2社目 |

- 橙と琥珀は、押す場所と印以外に敷かない。
- 橙の上の文字はカーボン。白だとコントラストが 2.4:1 しかない。
- ペリウィンクルの地に直接置く文字はカーボン。`chrome` は白い板の上の補足に使う。
- グラフの2色はカーボンと `systems-teal`。

## 書体

- `Noto Sans JP`（400 / 700 / 900）: 日本語の本文と見出し。
- `Archivo Black`: 表紙の箱文字。日本語の字形は Noto Sans JP 900 に落ちる。
- 本文は 14px 以上。構造のラベルは太く、字間を少し開ける。
- 数字は `font-num` で等幅。

## 形

- パネルは面取り。上辺を明るく、下辺を `chrome`。ぼかした影は使わない。
- 角は直角か 6px。45度の面取りは表紙のヒーローだけ。
- 丸はロゴピルと、進む円矢印だけ。
- ナビとフッターはカーボンに、細いハーフトーン。

## ユーティリティ

| 名前 | 役割 |
| --- | --- |
| `sheet` | 白い面取りの板 |
| `carbon-slab` | ハーフトーン付きのカーボン |
| `chamfer` | 表紙ヒーローの面取り |
| `box-art` | 白抜きと硬い影の箱文字 |
| `press` | 押すと 1px 沈む |
| `font-num` | 数字の等幅 |
| `on-paper` | キャラの白を明るい板に溶かす |

## 部品

| 部品 | 役割 |
| --- | --- |
| `AppHeader` | カーボンの主ナビと、その下の淡い帯。現在地は琥珀 |
| `SectionHeading` | 板の上端につくラベル |
| `CompanyCombobox` | 白い検索欄。表紙の決定は琥珀 |
| 業種タイル | `periwinkle` の system tile。進むときは橙の円矢印 |
| `RankRow` | プラチナの行。上位は白い板 |
| `LevelBadge` | 総合点の白い板。星は印として琥珀 |
| `CollectRule` | 溝に沈んだ尺。満ちる色は藍で、橙にしない |

## 画面幅

2001年の固定幅は採らない。広い画面は中央の最大幅、狭い画面はナビを横に送り、2列を1列に積む。押せる物の高さは 44px 以上。

## 動き

- 押したときの沈みと、尺が満ちる動きだけを残す。
- 数字は数え上げない。
- `prefers-reduced-motion` では動きを止める。
