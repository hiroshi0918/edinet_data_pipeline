# 会社図鑑デザインシステム「昼の絵本図鑑」

生成りの紙に、キャラの線画と同じ太い墨線で描いた絵本の図鑑。キャラは紙から飛び出すように動き、点数はゲームのステータスのように満ちていく。

トークンの正本は `src/index.css`。部品は `src/components/`。

## 色

アクセントは朱の1色だけ。キャラの絵がにぎやかなので、紙面は墨と紙で静かに保つ。

| トークン | 値 | 使う所 |
| --- | --- | --- |
| `paper` | `#FBF5E9` | 地 |
| `paper-deep` | `#F2E8D5` | 帯、ゲージの溝、ホバー |
| `page` | `#FFFDF7` | 紙面（`sheet`）、入力欄 |
| `ink` | `#2B211B` | 文字、線、ずらし影 |
| `ink-soft` | `#6B5E52` | 補足の文字（紙の上で 5.8:1） |
| `shu` | `#C63F28` | 押せる物と状態だけ（白文字で 4.98:1） |
| `marker` | `#FFE08A` | 見出しの蛍光ペンと総合点の飾りだけ |

- 朱は文字色に使うときも、押せる物か状態（1〜3位、判子、最新年の点）に限る。
- 蛍光ペンを地の色に広く敷かない。

## 書体

- `Zen Maru Gothic`（500 / 700 / 900）: 日本語のすべて。見出しは 900、本文は 500。
- `Nunito`（700 / 800 / 900）: 数字と英字。`font-num` ユーティリティで等幅数字になる。
- 3書体目を足さない。

## 形

- 線は `--line`（2.5px）の墨。
- 角丸は 14〜24px。紙面は `rounded-3xl`、チップとボタンは `rounded-full`。
- 目印は**ずらした墨の影**。`shadow-ink-sm`（2px）、`shadow-ink`（4px）、`shadow-ink-lg`（6px）。ぼかした影は使わない。
- 地には SVG のノイズで紙の粒を薄く敷く（`body`）。

## ユーティリティ

| 名前 | 役割 |
| --- | --- |
| `sheet` | 墨線の紙面。絵本の1ページ |
| `press` | 押せる物。ホバーで浮き、押すと影が縮んで沈む |
| `marker-line` | 見出しの蛍光ペン |
| `on-paper` | キャラ画像の白いにじみを紙に溶かす（`mix-blend-mode: multiply`） |
| `font-num` | 数字の書体と等幅数字 |

## 部品

| 部品 | 役割 |
| --- | --- |
| `AppHeader` | ロゴとしおり型のタブ。トップではヒーローに重ねて透明 |
| `SectionHeading` | 見出し。蛍光ペンの下線と、上に小さな見出し |
| `CharacterImage` | 業種のキャラ。サムネイルか本体、待機のふわふわ |
| `SpecimenFigure` | すみかの円の上のキャラと、図鑑番号・段階 |
| `LevelBadge` | 総合点の丸いバッジ。段階名と星 |
| `CollectRule` | 採集尺。HP バーのような太いゲージ |
| `FilterSelect` | 一覧の絞り込み。丸い `select` |
| `RankRow` | 一覧の1行。1〜3位は王冠 |
| `QueryState` | 読込はたまごが揺れる。空とエラーは吹き出し |

## 動き

| トークン | 値 | 使う所 |
| --- | --- | --- |
| `--dur-press` | 160ms | 押したとき |
| `--dur-reveal` | 320ms | 出現 |
| `--dur-gauge` | 700ms | ゲージが満ちる |
| `--ease-pop` | `cubic-bezier(.34,1.56,.64,1)` | 弾む物 |
| `--ease-out-soft` | `cubic-bezier(.22,1,.36,1)` | 出現、線を描く |

- 画面ごとに「1つの登場」を決める。表紙はロゴの文字が弾み、シートはキャラが現れてゲージが順に満ちる。
- 繰り返す動きは、キャラの待機と行進だけ。
- 数字は数え上げない。数字は最初から正しい値を出し、ゲージと飾りだけを動かす。
- `prefers-reduced-motion` では CSS の動きを止め、motion は `MotionConfig reducedMotion="user"` で止める。

## 画像

- キャラは `public/characters/webp/`（幅768px）と `public/characters/thumb/`（幅256px）の WebP を使う。元の PNG は `scripts/build-character-webp.sh` の入力。
- 一覧と行進はサムネイル、シートは本体。
- 紙の上では `on-paper` を掛ける。

## 文言

- 見出しは、その場所が何か、何ができるかを言う。
- 補足は1文。
