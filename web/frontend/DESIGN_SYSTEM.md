# 会社図鑑への当てはめ

見た目の正本は [DESIGN.md](DESIGN.md)（PlayStation の分析）。トークンの実装は `src/index.css`。部品は `src/components/`。

PlayStation のワードマークとロゴは使わない。ナビ左の印は既存のたまご。見出しの書体は Noto Sans JP の weight 300。

## 色

| トークン | 値 | 使う所 |
| --- | --- | --- |
| `canvas` | `#FFFFFF` | 地 |
| `primary` / `signal` | `#0070D1` | 進むボタン、現在地以外の強調、フッター |
| `carbon` | `#000000` | ナビ、表紙の導入、本文 |
| `periwinkle` / `lavender` | `#F5F7FA` | カードとキャラの台 |
| `platinum` / `canvas-soft` | `#F3F3F3` | 行の地、無効 |
| `chrome` | `#CCCCCC` | 枠線 |
| `ink-soft` | `#6B6B6B` | 補足 |
| `link` | `#0064B7` | 文章中のリンク |
| `amber` | `#D53B00` | 注意の印 |
| `brand` | `#C81B3A` | 失敗 |
| `compare-a` / `compare-b` | `#000000` / `#0070D1` | 比較の2社 |

- 青の全面はフッターだけ。ボタンの青は面ではない。
- 橙は注意だけ。進むボタンには使わない。
- グラフの塗りは UI の地色と分け、`#0070D1` `#004D8D` `#53B1FF` `#121314` を使う。

## 書体

- `Noto Sans JP`（300 / 400 / 500 / 700）。
- 題は 300。ボタンは 700。
- 本文は 16px。

## 形

- ナビは黒、高さ 48px。現在地は白、それ以外は白の 70%。
- フッターは `#0070D1`、白文字。
- カードは角 8px、影なし。クラス `sheet`。
- ボタンは pill。クラス `press` は押したときだけ色を落とす。

## 部品

| 部品 | 役割 |
| --- | --- |
| `AppHeader` | 黒い主ナビ |
| `SectionHeading` | 細い大きな題 |
| `CompanyCombobox` | 表紙では白い pill 検索。決定は青い pill |
| 業種タイル | `#F5F7FA` の角 8px。進むときは青い円 |
| `RankRow` | 上位3件はカード。順位の印は青い円 |
| `LevelBadge` | 総合点。星は青 |

## 画面幅

広い画面の本文は 1280px。表紙の黒と暗い帯、フッターは画面幅いっぱい。押せる物の高さは 44px 以上。

## 動き

- ページを開いたときの短い立ち上がりと、尺が満ちる動きだけを残す。
- `prefers-reduced-motion` では動きを止める。
