## EDA の本質：データ理解のプロセス

EDA は「統計検定」でも「仮説検証」でもなく、**データが何を言っているか理解する過程** です。

```
Data → 構造把握 → 単変量分析 → 欠損値確認 → 異常値検出 → 相関分析 → 仮説形成
```

各ステップで「次に何を見たいか」が自動的に浮かぶようになれば、EDA の技が身についた状態です。

## フェーズ別ガイド

### フェーズ 1：全体像把握（「何か」を知る）

**やること：**
- `df.shape` → 行数・列数を見る
- `df.info()` → データ型と非 NULL 件数を確認
- `df.head()` → 最初の何行かを眺める

**問い：**
- このデータセットは「何を」記録している？
- 粒度は何か（1行 = 1企業？1企業-年度？）
- 観測数は十分か？

**EDINET データの場合：**
```
✓ 1行 = 1企業・1会計年度
✓ 174 行 = 174社・年度の組み合わせ
✓ 複数年度・複数企業が混在
```

---

### フェーズ 2：単変量分析（各列を個別に見る）

**やること：**
```python
df['sales'].describe()  # 平均、中央値、分散など
df['sales'].hist()      # 分布を可視化
```

**チェックポイント：**
- **平均と中央値の乖離** → 外れ値（異常に大きい/小さい値）の存在を示唆
- **min/max** → 妥当な範囲か？（例：売上が負数？従業員数が 0？）
- **標準偏差** → 値のばらつきが大きいか小さいか

**何が見えるか：**
| 指標 | 平均 | 中央値 | 意味 |
|------|------|--------|------|
| 売上高 | 大 | 小 | 大企業が数社、中小企業が大多数 |
| 女性管理職比率 | 中 | 中 | わりと均等に分布 |

---

### フェーズ 3：欠損値（「ない」データを把握）

**なぜ重要か：**
- 古い指標（2010年度）と新しい指標（2024年度）では、欠損の有無が異なる
- 欠損 50% なら、「その指標を含むサンプル」だけで分析する必要がある
- 欠損が非ランダム（大企業だけ欠損、など）なら、バイアスの可能性

**EDINET データの場合：**
```
✓ sales / profit: ほぼ欠損なし（財務報告書の標準項目）
✓ female_manager_ratio: 2010 年代後半から本格化
✓ male_childcare_leave_ratio: 最近の指標なので、古い年度は欠損が多い
```

**欠損パターンの分析：**
```python
# 欠損は年度に依存するか？
df.groupby('fiscal_year')['female_manager_ratio'].apply(lambda x: x.notna().sum())
```

もし「2020年度以降のデータのみで分析」することになったら、サンプル数が 30 に減るかもしれません。その場合、「2020年以降の企業の女性管理職比率」という条件付き分析になります。

---

### フェーズ 4：異常値検出（「おかしい」値を見つける）

**異常値 ≠ 不適切な値**

例えば、「売上が 5 兆円」なら、トヨタなどの超大企業なので正当です。
一方、「従業員数が −100」なら、入力エラーです。

**検出方法：**

1. **IQR 法**（最も一般的）
   - Q3 + 1.5×IQR より大きい = 異常
   - Q1 − 1.5×IQR より小さい = 異常

2. **Z-score 法**
   - |z| > 3 （平均から 3 標準偏差以上）= 異常

3. **ドメイン知識**（最も大切）
   - 女性管理職比率が 150% → 絶対おかしい
   - 従業員数が 100 万人 → 超大企業なら正当、小企業なら疑問

**EDINET データの場合：**
```
売上が 5 兆円の企業 → 正当（トヨタなど）
女性管理職比率が 80% → 正当（ベンチャーなど）
売上が負数 → 絶対異常（エラー）
```

---

### フェーズ 5：多変量分析（複数の変数の関係）

#### 5.1 相関分析

**相関係数 r の解釈：**
- `|r| > 0.7` → 強い関係（一方が増えると他方も増える）
- `0.4 < |r| < 0.7` → 中程度の関係
- `|r| < 0.4` → 弱い関係
- `r = 0` → 無関係

**⚠️ 重要：相関 ≠ 因果**

例：「女性管理職比率と売上」に r=0.6 の相関があっても：
- A：女性管理職を増やしたから売上が上がった（因果）
- B：売上が多い企業は人事施策に余裕があり、女性を登用する傾向（逆因果）
- C：別の要因（業種など）が両方に影響（混乱変数）

→ **相関グラフから因果は言えない**。別の分析が必要。

#### 5.2 グループ分析

```python
# 企業規模で分けて、人的資本指標を比較
df[df['sales'] > 1000000000].groupby('fiscal_year')[['female_manager_ratio']].mean()
```

### フェーズ 6：時系列トレンド

**年度別に平均値を追うことで、業界全体の動きが見える：**

```
女性管理職比率 2015年度 → 2020年度 → 2024年度
          5% → 8% → 12%
```

→「法制度の変化や社会的プレッシャーで、女性管理職が増えている」という仮説が立つ。

## 実践的な分析フロー

### Case 1：「女性管理職比率が高い企業の特性は？」

```python
# 1. 上位 10% と下位 10% に分ける
high_ratio = df['female_manager_ratio'] >= df['female_manager_ratio'].quantile(0.9)
low_ratio = df['female_manager_ratio'] <= df['female_manager_ratio'].quantile(0.1)

# 2. それぞれの平均売上を比較
print(df[high_ratio]['sales'].mean())
print(df[low_ratio]['sales'].mean())

# 3. 企業数や業種の分布を見る
print(df[high_ratio]['company_name'].value_counts().head())
```

### Case 2：「年度別のトレンドを確認」

```python
# グループ化して平均値を計算
yearly = df.groupby('fiscal_year').agg({
    'sales': 'mean',
    'female_manager_ratio': 'mean',
    'male_childcare_leave_ratio': 'mean'
})

yearly.plot()
```

### Case 3：「欠損率が高い指標を除いて、有効なサンプルだけで分析」

```python
# female_manager_ratio が非欠損のレコードだけ
df_filtered = df[df['female_manager_ratio'].notna()]
print(f'有効サンプル数: {len(df_filtered)}')

# その中で相関を計算
df_filtered[['sales', 'female_manager_ratio']].corr()
```

## よくある落とし穴

| 落とし穴 | 対策 |
|---------|------|
| 欠損値を無視して分析 | `notna()` で欠損を明示的に処理 |
| 異常値を調べずに平均を計算 | まず箱ひげ図で異常値を確認 |
| 相関から因果を推論 | 「相関がある」までにとどめ、因果は別の分析で |
| サンプル数が減ったのに気づかない | 各フェーズで `len(df)` を確認 |
| 一つの指標だけで判断 | 複数の指標を組み合わせて見る |

## 次のステップ（EDA の先）

EDA の後、以下のような分析に進むことができます：

1. **記述統計** → EDA の発展版。より詳細な統計量（歪度、尖度）を計算
2. **推測統計** → グループ間に統計的に有意な差があるか、t検定など
3. **回帰分析** → 「女性管理職比率が、売上にどの程度影響するか」を定量化
4. **機械学習** → 企業の特性から「女性管理職比率を予測」など

## まとめ

EDA は「こういう流れで見ればいい」という**テンプレート** ですが、本質は **「データ」と「対話」** することです。

```
グラフを見る → 疑問が生じる → 別の角度から見る → 発見 → 仮説
```

このループが回れば、EDA が身についた状態です。🎯
